<br>

> An advanced AI-powered system for real-time deepfake voice detection and speaker verification, designed to combat synthetic audio fraud and ensure voice authentication integrity.

<table>
<tr><td><b>Stack</b></td><td>Python, TensorFlow, PyTorch, Flask, WebSockets</td></tr>
<tr><td><b>Scale</b></td><td>Real-time audio stream processing with sub-second latency</td></tr>

<tr><td><b>Security</b></td><td>End-to-end encrypted audio pipelines, secure model inference</td></tr>
<tr><td><b>Impact</b></td><td>Protects against voice-based identity fraud and deepfake attacks</td></tr>
<tr><td><b>Repository</b></td><td><a href="https://github.com/tohidealamnadaf/EchoClean"><img src="https://img.shields.io/badge/GitHub-EchoClean-7c3aed?style=flat-square&logo=github&logoColor=white&labelColor=1a0533" alt="Repo"/></a></td></tr>
</table>

EchoClean leverages state-of-the-art deep learning architectures including **CNNs**, **Transformers**, and **audio embedding models** to analyze speech patterns in real-time. The system extracts mel-spectrograms, MFCCs, and temporal features to distinguish genuine human speech from AI-generated synthetic audio. Built with a modular pipeline architecture, it supports both batch processing and real-time streaming inference via WebSocket connections.

</details>

<tr><td><b>Stack</b></td><td>Python, TensorFlow, Keras, Flask, OpenCV</td></tr>

<tr><td><b>Impact</b></td><td>Democratizes dermatological screening for underserved communities</td></tr>
<tr><td><b>Repository</b></td><td><a href="https://github.com/tohidealamnadaf/SkinScan-AI"><img src="https://img.shields.io/badge/GitHub-SkinScan--AI-7c3aed?style=flat-square&logo=github&logoColor=white&labelColor=1a0533" alt="Repo"/></a></td></tr>
</table>

SkinScan AI employs **transfer learning** with pre-trained architectures (ResNet, EfficientNet) fine-tuned on curated dermatological datasets. The system features an ensemble classification pipeline combining multiple model predictions with confidence scoring. Deployed as a RESTful API with a clean web interface, it provides instant diagnostic suggestions with explainable AI visualizations using Grad-CAM heatmaps.
